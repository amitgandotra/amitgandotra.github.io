# amitgandotra.github.io

Becoming FDE: a static, self-paced learning path for Forward Deployed Engineers
(Python, DSA, design patterns, enterprise integration, and more on the roadmap).
Plain HTML/CSS/JS, no build step required to serve it.

- Run locally: `python3 -m http.server 8000` then open http://localhost:8000
- **Start here if you are an AI assistant or a new contributor:** [docs/website-info.md](docs/website-info.md) (architecture, data model, conventions, workflows, pitfalls)
- Site structure and how to add lessons/topics: [docs/site-structure.md](docs/site-structure.md)
- Planned topics: [docs/todo.md](docs/todo.md)
- After changing lessons: `node tools/build-search-index.js`
